### 🚀 Featured Projects

**[VJTI Canteen](https://github.com/KumarTambe/VJTI-canteen-React)** — Full-stack canteen management system · [Live Demo](https://vjti-canteen-react.vercel.app/)
A platform for 18+ dishes across 4 categories with live order tracking. Built a personalised
dish recommender using the Gemini API that reads order history to suggest meals — a real
LLM layer, not a wrapper. JWT auth with role-based access separates student and admin
permissions; backend on a clean MVC structure, deployed on Render.

**[Veloura](https://github.com/KumarTambe/Veloura)** — Luxury watch e-commerce platform · [Live Demo](https://veloura-chi.vercel.app/)
Full component hierarchy for a storefront — product listing, cart, and checkout — with
client-side routing across 5+ pages for instant navigation. CI/CD on Vercel: every merged
commit ships to production automatically.

**[NIRN.AI](https://github.com/Pushkarbhangale15/NIRN.Ai)** — AI-assisted Government Resolution drafting tool · 🏆 1st place, VJTI AI Hackathon 2026
Built for Maharashtra's civil administration — fully on-premise (Ollama + FAISS + local
Postgres, nothing leaves the machine). I owned the FastAPI backend, PostgreSQL schema,
JWT auth with a three-tier role hierarchy, and an AI conflict-resolution feature that
rewrites clauses when two drafts conflict. Built with a 4-person team.

**CampusHire** — Campus placement portal *(in progress)*
MERN + TypeScript. Three roles (student/recruiter/admin), an eligibility engine, and a full
application workflow with audit logging. Backend auth and schema are live; frontend build
underway.
